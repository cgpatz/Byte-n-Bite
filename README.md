# Byte-n-Bite
A gamified learning programming game that teaches learners and beginners the fundamentals of programming and it's logic .

## Play in your browser

**https://cgpatz.github.io/Byte-n-Bite/**

The web version is built and published automatically by GitHub Actions
(`.github/workflows/web.yml`) every time `main` is pushed. Saves and settings
are kept in your browser. Works best in Chrome or Edge on a computer
(keyboard and mouse).
